# Hello

Ask it anything and it answers with the word "hello" — in the language you asked
in. That is all it does, and it does it over MCP, so it works from Claude Code,
Claude.ai and anything else that speaks the protocol.

## Who it is for

Anyone wiring up their first MCP connection who wants a server that cannot go
wrong before trying one that can.

## Start

Connect with the command on the card, then ask: *say hello in Uzbek*.
